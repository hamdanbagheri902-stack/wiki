# WikiSite

A static classic encyclopedia-style website.

## Open it

Double-click `index.html` in the project folder. No Node server, Command Prompt window, database, or install command is required to view the site.

## Add another article

Copy `history-of-computers.html`, rename the copy, replace the title and article content, then add the new article title and filename to `articleMap` in `script.js`.

## Put it online

Upload these static files to a static web host. After that, a registered `.org` domain can be pointed at that host using the host's DNS instructions.

The visual design is inspired by classic encyclopedia/wiki layouts. It does not use Wikipedia branding or claim affiliation with Wikipedia or Wikimedia.
